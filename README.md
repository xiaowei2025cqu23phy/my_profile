## 🛠️ 科研项目

### 🔄 项目一（进行中）— *基于应变片的水流速检测系统*

**项目类型**：2026 年大学生市级创新创业项目  
**指导老师**：郑雪丽

利用应变片的压阻效应，将其贴合在靶件材料上感知水流冲击产生的微小形变，通过惠斯通单桥电路将阻值变化转换为电压信号，再经 AD620 仪表放大器进行高精度放大。放大后的模拟信号由 ESP-32 微控制器采集，并通过其内置蓝牙模块无线传输至微信小程序端进行实时数据展示与分析。同时使用 ANSYS 对靶件结构进行流固耦合仿真，优化传感器灵敏度与线性度。本人与队友合作完成了电路设计与搭建、嵌入式程序编写及系统整体集成测试。

`应变片` `惠斯通电桥` `AD620` `ESP-32` `蓝牙通信` `微信小程序` `C++` `ANSYS`

### 🏆 项目：竞赛 — *基于RC弛豫振荡电路的第二帕邢电离常数测量*

**项目类型**：2026 年全国大学生物理实验竞赛（西南赛区）一等奖

针对传统气体放电测量中击穿电压瞬态随机性难以精准捕捉的痛点，提出了一种基于RC自持弛豫振荡的常压空气帕邢常数测定方法。将RC充放电电路与可调平行板气隙耦合，利用电离导通时电容充放电形成的稳态周期性振荡，将随机瞬态的击穿电压转化为稳定的宏观振荡频率进行测量。基于汤森电离理论建立频率-击穿电压的动力学模型，经对数线性化后通过最小二乘法拟合反演。测得空气第二帕邢电离常数 B = 270.0 V/(m·Pa)，R² = 0.9632，相对误差仅 1.24%。方案无需复杂真空系统，装置低廉、易于搭建。

`气体放电` `帕邢定律` `弛豫振荡` `RC电路` `FFT` `最小二乘法` `示波器`

### ✅ 项目二（已完成）— *量子证据保真度研究*

**项目类型**：2023–2024 年 SRTP 项目  
**指导老师**：肖富元

证据理论（Dempster–Shafer 理论）是一种处理不确定性信息的数学框架，本项目将其推广至量子体系，研究量子证据保真度的定义、基本性质与计算方法。保真度是衡量两个量子态之间相似程度的重要度量，在量子态估计与量子测量分析中具有核心地位。本人与队友通过查阅文献推导了量子证据保真度的若干数学性质，并利用 Python 进行数值模拟，验证了理论结果的有效性，为后续将证据理论应用于量子信息处理奠定了方法基础。

`Python` `NumPy` `Matplotlib` `量子信息`

### 📗 项目三（课程项目）— *基于手势识别的快捷操作系统*

**课程名称**：智慧图像处理  
**指导老师**：伍星

以 IPN 手势数据集（包含 14 类手势、5 种复杂背景）为训练数据，基于 ResNet34 残差网络构建图像分类模型，解决深层网络训练中的梯度消失问题。模型在测试集上达到较高准确率后，通过 PyQt 搭建桌面应用，调用摄像头进行实时手势识别，并引入状态机机制实现多手势的逻辑组合触发自定义快捷键操作（如切换窗口、播放控制等），实现了从模型训练到应用落地的完整闭环。本人与队友完成了数据预处理、模型训练与调优、以及桌面端应用开发。

`Python` `PyTorch` `ResNet` `计算机视觉` `深度学习` `状态机` `PyQt` `手势控制`

### 📄 项目四（竞赛项目）— *Island Cloud Spatiotemporal Prediction Model*

**项目类型**：2025 MCM 校内选拔赛

Islands, as isolated land surfaces within the ocean, provide ideal settings for studying sea–land–atmosphere interactions. Their localized thermal and dynamic structures critically control cloud formation. Using prescribed background winds, SST, topography, and atmospheric stratification, this study develops a coupled island cloud prediction model that integrates key thermal and dynamic processes. The model consists of a thermo-dynamic core that simulates the evolution of the island's thermal structure and the resulting sea-breeze circulation, coupled with a cloud microphysics module that predicts cloud formation based on the simulated atmospheric conditions. The model is validated against observational data from field campaigns and satellite measurements, demonstrating its ability to capture the spatiotemporal variability of island clouds. Sensitivity analyses reveal the critical roles of SST gradients and topographic features in modulating cloud development.

`数值模拟` `海陆气耦合` `大气物理` `MCM` `python`

### 🎱 项目五（竞赛项目）— *Lato-lato 球运动模式分析*

**项目类型**：2025 年物理学术竞赛课题

Lato-lato 是一种传统的菲律宾玩具，由两个球通过绳子连接，玩家通过旋转和抛掷使球在空中运动。本项目通过建立 Lato-lato 球的动力学模型（基于牛顿第二定律，考虑重力、绳子张力、空气阻力等因素），分析其运动模式与稳定性。数值模拟发现其运动模式主要分为两类：**稳定旋转模式**（球沿固定轨迹运动）和**不稳定抛物线模式**（表现出复杂的非线性行为）。进一步的参数分析表明，绳子的长度和初始旋转速度是影响运动模式的关键因素。

`动力学分析` `探究实验` `Python`  `物理建模`

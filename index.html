基于应变片的水流速检测系统

2026 年大学生创新创业项目 · 指导老师：郑雪丽

利用应变片的压阻效应，将其贴合在靶件材料上感知水流冲击产生的微小形变，通过惠斯通单桥电路将阻值变化转换为电压信号，再经 AD620 仪表放大器进行高精度放大。放大后的模拟信号由 ESP-32 微控制器采集，并通过其内置蓝牙模块无线传输至微信小程序端进行实时数据展示与分析。同时使用 ANSYS 对靶件结构进行流固耦合仿真，优化传感器灵敏度与线性度。本人与队友合作完成了电路设计与搭建、嵌入式程序编写及系统整体集成测试。

应变片 惠斯通电桥 AD620 ESP-32 蓝牙通信 微信小程序 C++ ANSYS
已完成

量子证据保真度研究

2023–2024 年 SRTP 项目 · 指导老师：肖富元

证据理论（Dempster–Shafer 理论）是一种处理不确定性信息的数学框架，本项目将其推广至量子体系，研究量子证据保真度的定义、基本性质与计算方法。保真度是衡量两个量子态之间相似程度的重要度量，在量子态估计与量子测量分析中具有核心地位。本人与队友通过查阅文献推导了量子证据保真度的若干数学性质，并利用 Python 进行数值模拟，验证了理论结果的有效性，为后续将证据理论应用于量子信息处理奠定了方法基础。

Python NumPy Matplotlib 量子信息
课程项目

基于手势识别的快捷操作系统

智慧图像处理 · 指导老师：伍星

以 IPN 手势数据集（包含 14 类手势、5 种复杂背景）为训练数据，基于 ResNet34 残差网络构建图像分类模型，解决深层网络训练中的梯度消失问题。模型在测试集上达到较高准确率后，通过 PyQt 搭建桌面应用，调用摄像头进行实时手势识别，并引入状态机机制实现多手势的逻辑组合触发自定义快捷键操作（如切换窗口、播放控制等），实现了从模型训练到应用落地的完整闭环。本人与队友合作完成了数据预处理、模型训练与调优、以及桌面端应用开发。

Python PyTorch ResNet 计算机视觉 深度学习 状态机 PyQt 手势控制
竞赛项目

Island Cloud Spatiotemporal Prediction Model

2025 MCM 校内选拔赛

针对海洋孤立岛屿的海-陆-气相互作用，构建了一个耦合热力学-云微物理模型，综合考虑背景风场、海表温度、地形和大气层结等因素，预测岛屿云团的时空演变。模型通过热力-动力核心模拟岛屿热力结构与海风环流，耦合云微物理模块预测云的形成与演化，并利用现场观测与卫星数据进行验证。本人与队友共同完成了模型搭建、数值求解及敏感性分析。

数值模拟 大气物理 MATLAB MCM
竞赛项目

Lato-lato 球运动模式分析

2025 年物理学术竞赛课题

针对菲律宾传统玩具 Lato-lato 球，基于牛顿第二定律建立了包含重力、绳子张力、空气阻力的动力学模型。数值模拟发现其运动模式分为稳定旋转和不稳定抛物线两类，参数分析表明绳子长度与初始旋转速度是影响模式的关键因素。本人与队友负责模型推导、数值仿真与结果分析。

动力学分析 数值模拟 Python 物理建模
